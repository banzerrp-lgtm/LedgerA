# Paso 0 — Preparación del entorno
Adjuntar: PROYECTO.md

## Objetivo
Tener el proyecto vacío corriendo en tu computadora y guardado en GitHub.

## Al terminar debe existir
- Node.js (versión LTS) instalado.
- Carpeta `ledger` creada con Vite (plantilla vanilla) y se ve una página en el navegador.
- Git iniciado, primer commit y repositorio subido a GitHub.
- Dependencias instaladas: `dexie`, `vite-plugin-pwa`, `vitest`.
- Carpetas de PROYECTO.md sección 7 creadas, y los archivos .md dentro de `docs/`.

## Pide a la IA
Que te guíe comando por comando, explicando qué hace cada uno. Pregunta qué significa cada archivo que se crea.

## Prueba manual
`npm run dev` abre la página y cambia al editar `index.html`.

## Cierre
Commit "paso 0" y actualizar ESTADO.md.
